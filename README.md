# 🐍 Python 101 - Eğitim Materyalleri
Bu depo, 2026-2027 Döneminde Yönetim Kurulu Üyesi olduğum **Eskişehir Teknik Üniversitesi (ESTÜ) Yazılım Kulübü** adına hazırladığım ve sunduğum **Python 101** eğitiminin tüm materyallerini içermektedir.

Sıfırdan başlayan yazılım meraklıları için tasarlanan bu eğitim; yalnızca Python'un sözdizimini değil, genel yazılım konseptlerini, modüler mimariyi ve temiz kod yazma prensiplerini uygulamalı olarak öğretmeyi hedefler.
İsteyen tüm eğitmenlerin ve yazılım öğrenmek isteyen herkesin özgür kullanımına açıktır.

## 📚 Eğitim İçeriği (Müfredat)
Eğitim slaytı ve kod örnekleri aşağıdaki konu başlıklarını sırasıyla takip etmektedir:
1. **Neden Python?**

   * Kullanım alanları (Veri Mühendisliği, Web Geliştirme, AI \& NLP, Otomasyon).
   * Dilin felsefesi, popülerlik sebepleri ve sistemler arası entegrasyon gücü.
2. **Python Temelleri**

   * Temel veri tipleri (`int`, `float`, `str`, `bool`).
   * Dinamik tip belirleme (Dynamic Typing) ve Tip dönüşümleri (Typecasting).
   * String işlemleri ve formatlama.
3. **Koleksiyonlar (Veri Yapıları)**

   * `List`, `Tuple`, `Set` ve `Dictionary` yapıları.
   * Koleksiyon metotları ve Index mantığı.
4. **Kontrol Yapıları ve Döngüler**

   * Mantıksal operatörler ve `if/elif/else` koşul durumları.
   * `for` ve `while` döngüleri.
5. **Fonksiyonlar**

   * Fonksiyon tanımlama (`def`, `return`).
   * Parametre türleri (Konumsal, Keyword, Varsayılan, `\*args`).
   * Kapsam (Local ve Global değişkenler).
6. **Nesne Yönelimli Programlama (OOP)**

   * `Class`, `Object`, `Attribute` ve `Method` kavramları.
   * Yapıcı metot (`\_\_init\_\_`) ve `self` anahtar kelimesi.
   * Nesne yönelimli düşünme (Klima örneği üzerinden modelleme).
7. **Yazılım Prensipleri**

   * Temel prensipler: **DRY** (Don't Repeat Yourself), **KISS**, **YAGNI**, **SRP**.
   * Temiz kod: *No Magic Numbers* ve **PEP 8** standartları.
8. **Modüller ve Paket Yönetimi**

   * Standart kütüphanelerin kullanımı (`math`, `random`).
   * Kendi modüllerimizi yazma.
9. **Son Proje: Kura ve Grup Sistemi**

   * Öğrencileri rastgele gruplandıran modüler mimarili bitirme projesi.

## 🚀 Nasıl Kullanılır?

Projeyi kendi bilgisayarınızda çalıştırmak için:

1. Repoyu bilgisayarınıza klonlayın:

```bash
   git clone https://github.com/YusufAliRencuz/python101-egitim-materyali.git
   ```

2. Terminalden klasörün içine girin:

```bash
   cd python101-egitim-materyali
   ```

3. İncelemek istediğiniz dosyayı Python ile çalıştırın. Örneğin:

```bash
   python Uygulamalar/uygulama\_4.py
   ```
